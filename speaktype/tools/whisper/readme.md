# Whisper Binary

1.  Go to [whisper.cpp releases](https://github.com/ggerganov/whisper.cpp/releases).
2.  Download the latest Windows zip (e.g., `whisper-bin-x64.zip`).
3.  Extract **ALL** files from the zip (especially `main.exe` AND `whisper.dll`) into this folder.
4.  Ensure `main.exe` and `whisper.dll` are in the same directory.
